# GRAIN's samples

`tools/gen_samples.py` takes these to mono 16-bit at 22.05 kHz (cut, faded, one peak) for the GRAIN oscillator; it
makes the third, VOX (a voice on C4 through the vowels), itself.

| File | From | License |
|---|---|---|
| `vcsl-pipe-organ-quiet-C4.wav` | VCSL (Versilian Community Sample Library), `Aerophones/Edge-blown Aerophones/Pipe Organ/Quiet/NT5_Man3Quiet_C4_rr1.wav`; organ sampled by Simon Dalzell of Ivy Audio | CC0 1.0 |
| `vcsl-cowbell.wav` | VCSL, `Idiophones/Struck Idiophones/Cowbells/Cowbell1_Hit_v3_rr1_Mid.wav` | CC0 1.0 |

VCSL: https://github.com/sgossner/VCSL (CC0 1.0; credit to the authors and Versilian Studios is encouraged). Both as
the synth repo's `pcm/` has them: mono, 16 bit, 44.1 kHz, from the first sound, peak at -1 dBFS.
